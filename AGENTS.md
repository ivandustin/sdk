# Skills

Store repository skills in `/lib/skills` (relative to the repository root).
Place each skill in its own directory with a `SKILL.md` file containing its instructions.
Before using a repository skill, read its `SKILL.md` and follow the applicable instructions.

# Automatic commits

After completing a task and running the appropriate checks, automatically commit the task's changes without asking for confirmation.
Stage only changes made for the task; leave unrelated user changes untouched.
Use a concise, descriptive commit message and report the commit hash in the final response.
Do not push commits unless explicitly requested.
